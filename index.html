Send files to 3D-Prints

Pick files on this phone. They go straight into a folder in your private 3D-Prints repo.

One-time setup: GitHub key

No key is built into this page. The key you paste stays in this browser on this phone and is only sent to api.github.com.

1. Create the key on GitHub. Under Repository access choose Only select repositories, then 3D-Prints. Contents is already Read and write. Tap Generate token and copy it.

2. Paste it here:

Folder in 3D-Prints

    Each file is its own commit on main. If the name is already taken, the date and time are added so nothing is overwritten.
